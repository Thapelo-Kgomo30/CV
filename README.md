# Personal CV Website

A responsive personal CV website built using HTML and CSS. This project showcases my personal profile, education background, technical skills, and contact information in a clean and structured web layout.

## 📌 Project Overview

This website serves as an online curriculum vitae (CV) and portfolio introduction. It is designed to provide a simple, responsive, and visually appealing presentation of my professional and educational background.

## 🚀 Features

- Responsive webpage layout
- Navigation menu for easy access to sections
- Personal profile section with image
- About Me section
- Education history
- Technical skills showcase
- Contact information
- Clean and modern typography using Google Fonts

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
